# SD Card Contents

Copy this entire folder to the **root of the SD card** before first use.

```
SD root/
├── raw/         10-min telemetry (daily CSV, pod writes)
├── inputs/      Hourly model feature vectors (pod writes)
├── pred/        Hourly model predictions (pod writes)
├── events/      Diagnostic events (pod writes)
├── model/       Model files (copy here manually after training)
│   ├── manifest.json    ← generated by pod-ml/scripts/export_model.py
│   └── model.bin        ← generated by pod-ml/scripts/export_model.py
└── maps/        Map tiles (generated by pod/tools/map_tile_gen.py on VM)
    ├── 2km/
    │   ├── regular/
    │   └── offset/
    └── 4km/
        ├── regular/
        └── offset/
```

## Model files

After training, run from the repo root:

```bash
python pod-ml/scripts/export_model.py \
  --model pod-ml/models/latest.pkl \
  --out pod/sd_card/model/
```

This writes `manifest.json` + `model.bin`. Copy the `model/` folder to the SD card.

## Map tiles

Generated on the VM with `pod/tools/map_tile_gen.py`. Copy the `maps/` folder to the SD card.
The pod reads tiles from `/maps/2km/regular/` (and offset/4km variants) based on GPS position.
