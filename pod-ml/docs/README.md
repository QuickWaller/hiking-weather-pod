## How the current model is built (code map)

The motion-aware pipeline lives in `src/podml/`:
- `motionsim.py` — simulate a moving hiker's signal history along a feasible path (Markov still/walk/drive,
  MSLP reduction + GPS-altitude error); `sensorsim.py` then degrades it; `features.py` builds the vector.
- `labels_gpm.py` — per-cell GPM rain labels (forward-window severity).
- `train_motion.py` — build-once cached dataset (`build_cache`), then everything reads the cache:
  `train_from_cache`, `learning_curve`, `compare_feature_sets`, `calibration_experiment`,
  `weighting_experiment`, `final_eval` (the authoritative all-cells run + atlas data).
- `report_motion.py` — figures + the `results-motion.md` report.
- `maps.py` — static domain maps (terrain, static vars, climatology).
